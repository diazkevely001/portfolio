From-Scratch Neural Network for PII Detection

Deep Learning Theory | Custom Neural Architectures | Data Privacy

Project & Business Context

A collaborative deep learning initiative designed to build a custom, multi-layer neural network from scratch for binary classification of Personally Identifiable Information (PII) in corporate documents. Built as an in-house security mechanism, the system scans business text to automatically detect and flag sensitive consumer and enterprise data before transmission—mitigating severe compliance, financial, and legal liabilities.

Key Methodologies & Technical Pillars

  • Data Engineering & Text Embeddings: Formatted and cleaned document datasets, transforming unstructured text into dense vector representations optimized for custom neural network inputs.
  • Custom Architecture & Backpropagation Mechanics: Implemented linear network layers, custom activation steps, loss functions, and forward/backward propagation algorithms from foundational mathematical principles.
  • Model Lifecycle & Live Inference: Executed 60-epoch training cycles to produce optimized static weight parameters, saving configurations to file for automated real-time inference testing on unseen text payloads.
