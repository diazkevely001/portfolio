Scalable Sentiment Classification: Word2Vec Vectorization and Document Length Benchmarking

Natural Language Processing (NLP) | Machine Learning | Semantic Embeddings

Project Overview

An end-to-end Natural Language Processing (NLP) machine learning pipeline designed to classify textual sentiment across massive social media datasets. Moving beyond traditional frequency-based text representations (such as TF-IDF or Bag-of-Words), this study implements dense, distributed word embeddings using Word2Vec skip-gram architectures on the 1.6-million-record Sentiment140 dataset.

Key Methodologies & Pipeline Architecture

  • Regex Text Preprocessing & Noise Reduction: Built automated text-cleaning pipelines to strip URLs, user mentions (@username), punctuation, special characters, and empty rows, followed by stratified train-test partitioning.
  • Word2Vec Skip-Gram Embeddings: Tokenized over 13.5M total tokens across a 400,000+ unique word vocabulary, generating 200-dimensional dense feature vectors via document-level embedding averaging.
  • Classification & Evaluation: Modelled sentiment using a multinomial Logistic Regression classifier with class weighting, achieving a consistent 75% overall test accuracy and balanced F1-scores (0.75 negative / 0.76 positive).
