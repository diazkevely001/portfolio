Serverless AWS Sentiment Microservice & Cross-Platform NLP Benchmarking

AWS Cloud Architecture | Serverless Computing | NLP & Benchmarking

Project Overview

Design, deployment, and performance benchmarking of a cloud-native sentiment analysis microservice engineered on Amazon Web Services (AWS). The microservice real-time processes short text payloads to categorize sentiment across four distinct states: positive, negative, neutral, and mixed. The study evaluates serverless cloud execution alongside comparative benchmarking across ChatGPT (GPT-4), Grammarly, AWS Comprehend, and a custom machine learning model.

Cloud Architecture & Methodology

  • Serverless AWS Infrastructure: Provisioned an API Gateway HTTP POST endpoint backed by AWS Lambda for scalable execution, using AWS Comprehend for real-time, zero-infrastructure NLP sentiment inference.
  • Dataset Blending & Synthetic Sampling: Constructed a multi-source text dataset combining Sentiment140, Kaggle entries, and author-generated synthetic data to address missing "mixed" class labels and mitigate dataset imbalance via oversampling and reweighting.
  • Cross-Platform Benchmarking: Conducted comparative performance evaluations on literary and mythological excerpts, analyzing contextual accuracy, figurative language processing, and literal sentiment boundaries across GPT-4, Grammarly, AWS Comprehend, and Logistic Regression.
