YOLOv5 vs. YOLOv8: Aerial View Object Detection & Benchmarking

Computer Vision | Deep Learning | Real-Time Object Detection | Performance Evaluation

Project Overview

A rigorous comparative study evaluating an anchor-based object detection model (YOLOv5) against a newer, anchor-free architecture (YOLOv8). Utilizing aerial vehicle detection datasets (~1,000 high-resolution parking lot images), the benchmark tracks model performance across three scaling sizes (Nano, Small, Medium) and 18 distinct training sessions to analyze learning convergence, validation loss stability, and real-time video inference speeds.

Key Methodologies & Benchmark Insights

  • Multi-Variant Training Pipeline: Trained 18 computational sessions combining 3 model scales (n, s, m) across 30, 50, and 100 epoch cycles to evaluate mAP@0.5, mAP@0.5:0.95, validation box loss, and classification loss.
  • Real-Time Inference & Hardware Profiling: Evaluated real-time video inference performance over intersection feeds, documenting computational overhead, memory demands, and latency differences between legacy and modern YOLO architectures.
  • Architectural Stability Comparison: Demonstrated that YOLOv5m achieved superior precision, smoother loss convergence, and lower validation box loss on constrained aerial data, whereas YOLOv8 exhibited loss volatility requiring early stopping and fine-tuned hyperparameter optimization.
