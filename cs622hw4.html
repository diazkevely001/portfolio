Neural Network & Convolutional Neural Network Benchmarking

Deep Learning | PyTorch | Computer Vision | Model Evaluation

Project Overview

A comparative evaluation of a standard Feedforward Neural Network (NN) and a Convolutional Neural Network (CNN) built with PyTorch. Evaluated on the USPS handwritten digits dataset using a stratified 5-fold cross-validation setup, the study analyzes architectural trade-offs, spatial feature extraction, and generalization efficiency across deep learning frameworks.

Preprocessing & Model Architectures

  • Data Pipeline & Preprocessing: Filtered OpenML data to digits 0–9, standardized features via StandardScaler, and reshaped flat input vectors into 16×16 single-channel grayscale image matrices for spatial convolution.
  • Feedforward Neural Network (NN): Built a dense PyTorch network (256 → 128 → 64 → 10) with ReLU activations, CrossEntropy Loss, and Adam optimization, achieving 97.33% ± 0.24% average accuracy across 5 folds.
  • Convolutional Neural Network (CNN): Designed a lightweight PyTorch CNN utilizing 2D convolutions (8 filters, 3×3 kernel), ReLU, 2×2 max-pooling, and dense linear layers (512 → 64 → 10), achieving 97.66% ± 0.46% average accuracy by preserving spatial topology.
